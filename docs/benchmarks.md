# **Benchmarks**

Performance numbers from the team's own load test run. The TA reproduces  
this on their hardware during Phase 1 grading.

## **Hardware Profile**

* CPU: Intel x86_64, 8 cores  
* Memory: 32 GB  
* Disk: SSD, 50 GB free  
* Network: 100 Mbit  
* OS: Windows 11 / WSL2  
* Container runtime: Docker 24.x  
* Orchestration: Docker Compose v2

## **Methodology**

Load test driver: Locust 2.x (tests/load/locustfile.py).  
Run command:  
locust -f tests/load/locustfile.py \  
  --headless -u 50 -r 10 --run-time 1m \  
  --host=http://localhost:8080 \  
  --csv=reports/benchmarks

* -u 50 — 50 concurrent users  
* -r 10 — ramp up at 10 users/second  
* --run-time 1m — sustained load for 60 seconds  
* Headline endpoints: POST /api/kitchen/webhook, GET /health, GET /
