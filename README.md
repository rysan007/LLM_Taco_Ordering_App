# **The Neon Trompo Voice Agent**

A low-latency, multi-LLM conversational AI designed specifically for a Tex-Mex food truck. It handles native voice ordering, rigorous cart state management, and asynchronous Human-in-the-Loop (HITL) approvals from the kitchen staff for complex dietary requests, eliminating "vibe coding" hallucinations in the checkout process.

## **Tech Stack**

* Python 3.11  
* Web framework: FastAPI (WebSockets & Webhook Routing)  
* Model provider: Google Gemini API (2.5 Flash & 2.5 Pro)  
* Audio Pipeline: Retell AI  
* Environment: Docker + Docker Compose + Ngrok (Webhook Tunneling)

## **Quick Start**

The TA will run exactly these commands. Make sure they work on a fresh clone with no extra setup.  
git clone [https://github.com/](https://github.com/)[your-org]/[your-repo].git  
cd [your-repo]  
cp .env.example .env  
# edit .env and fill in the required GEMINI, RETELL, and NGROK keys  
docker compose up

Wait for all services to report healthy. The application will be available at http://localhost:8080.  
*(Note: As approved by the instructor, the Ngrok container will automatically handle public tunneling for Retell's WebSocket connection).*  
Estimated time from docker compose up to running app: **under 10 minutes** on a clean machine.
